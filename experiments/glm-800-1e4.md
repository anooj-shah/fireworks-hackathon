## Notes
- **A loser on the selection metric:** training moved the Grouped (demographic) half +8.3 but left Pop flat. The untrained GLM is already strong on Pop (32.4, the best untrained open model).
- **37 / 1,490 unparseable outputs** (2.5%; 30 of them in Pop), all with the same failure: a stray token in place of a number, e.g. `{"A": 71, "B": 21, "C": 5, "D":  TA, "E": 3}`. The official grader scores these as a uniform guess. Untrained GLM had 0.
- Examples (dev Pop):
  - `pop-1754` (Moral Machine). Real A 86 / B 14. Base `{"A": 12, "B": 88}` (S = −241). FT `{"A": 88, "B": 12}` (S = 89).
  - `pop-1319` (Moral Machine). Real A 8 / B 92. Base `{"A": 85, "B": 15}` (S = −254). FT `{"A": 23, "B": 77}` (S = 32).
  - Worst regression, `pop-2192`. Real A 65 / B 5 / C 30. Base `{"A": 85, "B": 5, "C": 10}` (S = 48). FT `{"A": 0, "B": 100, "C": 0}` (S = −148). An overconfident one-hot answer.
- Softening (`eval/soften.py --fit`, λ = 0.2) was reported to raise dev Pop, but that run isn't saved to `results/` yet, so it isn't quoted here.
- GLM is ~5× the cost per answer of Nemotron or Qwen on the sampler ($0.91 vs ~$0.19 per 1k).
