## Notes
- **Biggest gain in the shortest training.** 800 examples (50 steps) moved Pop +10.3, against +20.3 for Qwen on 3,000. But Nemotron starts much higher (24.9 vs 10.1 untrained), so it ends up the best single fine-tune: 35.2 vs Qwen 30.4 and GLM 32.4.
- Matches Sonnet on dev Pop at about 1/6 of Sonnet's cost per answer. Still clearly below Opus.
- Examples (dev Pop; real = survey answer):
  - `pop-441` (gambling-machine choice, US MTurk). Real A 15 / B 85. Base `{"A": 100, "B": 0}` (S = −386). FT `{"A": 10, "B": 90}` (S = 71).
  - `pop-1754` (Moral Machine dilemma). Real A 86 / B 14. Base `{"A": 10, "B": 90}` (S = −250). FT `{"A": 80, "B": 20}` (S = 74).
  - The worst regression, `pop-6351` (number-sequence judgment). Real A 25 / B 75. Base `{"A": 30, "B": 70}` (S = 82). FT `{"A": 91, "B": 9}` (S = −142). The fine-tune can be confidently wrong.
- Softening (`eval/soften.py --fit`): the training session reported a better dev Pop with λ = 0.15, but that run isn't saved to `results/` yet, so it isn't quoted here. Commit it before using the number.
- **For the demo:** it's 120B, so check the deployment shape (GPU count, $/hr) before picking it as the live model.
